# 📝 Journali

Journali is an iOS journaling app that gives you a calm, simple space to write down your thoughts and come back to them whenever you like. Create entries, bookmark the ones that matter, and find any of them quickly with search and filters.

## ✨ Main Features

- **Splash screen** – a welcoming launch screen when the app opens.
- **Empty state** – a friendly "Begin Your Journal" screen shown until you write your first entry.
- **Add a journal** – write a title and your thoughts, then save with one tap.
- **Edit a journal** – open any entry and update it at any time.
- **Delete a journal** – swipe on an entry to delete it.
- **Bookmark entries** – mark your favorite entries so they are easy to find.
- **Search** – search through your journals by title.
- **Filter** – show only bookmarked entries, or sort and filter by date.
- **Dark interface** – a dark theme with a purple accent color.

## 🛠 Technologies Used

- **Swift**
- **SwiftUI**
- **MVVM architecture** (Model – View – ViewModel)
- **SF Symbols** for icons
- **Xcode**

## 🗂 Project Structure

| Folder | What it contains |
| --- | --- |
| `Model` | The data of the app (`Journal`, app colors) |
| `ViewModel` | The logic behind the screens (`JournalViewModel`, `AddJournalViewModel`) |
| `View` | The screens the user sees (splash, journal list, add/edit journal) |

## ▶️ How to Run

1. Clone the repository.
2. Open `Journali.xcodeproj` in Xcode.
3. Choose an iPhone simulator.
4. Press **Run** (▶).
